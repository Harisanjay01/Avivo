# User Directory

A simple full-stack app using React, Express, Prisma, and MySQL.

## Setup

1. **Backend**:
   - `cd backend`
   - `npm install`
   - `npx prisma db push`
   - `npm run seed`
   - `npm run dev` (Runs on port 5001)

2. **Frontend**:
   - `cd frontend`
   - `npm install`
   - `npm run dev` (Runs on port 5175)

## Features
- Fetch users from database
- Search and filter users
- Add users locally
- Delete users locally
